## 🚀 Getting Started (3 Simple Steps)

### Step 1: Install Dependencies
```bash
cd portfolio-website
npm install
```

### Step 2: Start Development Server
```bash
npm run dev
```
Your portfolio opens at `http://localhost:5173`

### Step 3: Customize with Your Information
Edit files in `src/` to add your:
- Name and title
- About information
- Skills
- Projects
- Experience
- Contact info

**See `QUICK_REFERENCE.md` for exact file locations!**

## 💡 Key Customizations

### Change Your Name (Easiest)
1. Open: `src/sections/HeroSection.jsx`
2. Find: `Hi, I'm <span>Your Name</span>`
3. Replace: "Your Name" with your actual name
4. Save and refresh browser ✅

### Add a Project
1. Open: `src/sections/ProjectsSection.jsx`
2. Find: `const projects = [`
3. Add a new object with project details
4. The site automatically displays it ✅

### Update Skills
1. Open: `src/sections/SkillsSection.jsx`
2. Edit the `skillCategories` array
3. Add/remove/modify skills and percentages ✅
